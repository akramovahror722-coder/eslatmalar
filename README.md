# Eslatmalar

Brauzerda ishlaydigan, avtomatik saqlanadigan shaxsiy eslatmalar.

## Imkoniyatlar

- Avtomatik saqlash (`localStorage`)
- Teglar, qidiruv va saralash
- Muhim eslatmalarni mahsiylash
- So'z va belgi hisobi
- JSON eksport va import
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

React · TypeScript · Vite · Tailwind CSS · localStorage · JSON

## Ishga tushirish

```bash
npm install
npm run dev
```
